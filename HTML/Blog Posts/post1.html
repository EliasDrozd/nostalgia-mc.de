1.21.4 SMP Eröffnung!

Unser erster Server ist Online!

Hi zusammen,

willkommen zum ersten Blog Post! Ich kann mit Freude berichten, dass der erste Minecraft-Server für euch nun endlich Online zur Verfügung steht. Weiter unten könnt Ihr die genauen Daten des Servers einsehen.

Unser erster Server ist ein gewöhnlicher SMP-Server auf der neuen Java Version 1.21.4. Eure Clients müssen diese Version verwenden, da Ihr sonst leider nicht mit einer gültigen Version euch mit unserem Server verbindet. Aber keine Bange: wir sind dabei ein Plugin zu installieren und einzurichten, welches euch erlaubt mit so gut wie jeder Client Version euch zu Verbinden!
